# 🚀 Animated Tech Stack Showcase with Framer Motion & TailwindCSS

This project is a smooth, **infinite scrolling tech stack banner** built using **React.js**, **Framer Motion**, and **TailwindCSS**—perfect for portfolios or developer landing pages to showcase tools and technologies creatively.

---

## ✨ Features

- 🔁 Infinite horizontal scrolling animation with **Framer Motion**
- 🧩 Responsive layout styled using **TailwindCSS**
- 🎯 Lightweight, minimal, and customizable
- 💡 Future-ready for interactions and hover effects
